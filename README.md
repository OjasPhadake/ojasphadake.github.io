# ojasphadake.github.io

Personal website of **Ojas Phadake**, IIT Madras: quant finance, control and optimization, and machine learning.

Live at **[ojasphadake.github.io](https://ojasphadake.github.io)**.

Built on [al-folio](https://github.com/alshedivat/al-folio) (Jekyll) and deployed to GitHub Pages by the `deploy` workflow on every push to `main`.

## Where things live

| What          | File                                                                      |
| ------------- | ------------------------------------------------------------------------- |
| Home page bio | `_pages/about.md`                                                         |
| News items    | `_news/`                                                                  |
| Project pages | `_projects/` (category `quant` or `control`; `importance` sets the order) |
| Publications  | `_bibliography/papers.bib`                                                |
| Résumé PDF    | `assets/pdf/Ojas_Phadake_Resume.pdf`                                      |
| Social links  | `_data/socials.yml`                                                       |
